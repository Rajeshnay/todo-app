# Full Stack To-Do Application

## Project Overview

This is a Full Stack To-Do Application where users can add, update, delete, and mark tasks as completed.
The project is built using React for the frontend and Node.js with Express for the backend.

---

## Technologies Used

* Frontend: React
* Backend: Node.js, Express.js
* Styling: CSS
* Data Format: JSON

---

##  Features

*  Add new tasks
*  Edit tasks
*  Delete tasks
* Mark tasks as completed
*  Real-time updates using API

---

##  Project Structure

frontend (React)
todo-app/

backend (Node.js)
crud-app/
├── server.js

---

## 🔗 API Endpoints

| Method | Endpoint       | Description   |
| ------ | -------------- | ------------- |
| POST   | /add           | Add new task  |
| GET    | /get           | Get all tasks |
| PUT    | /update/:index | Update task   |
| DELETE | /delete/:index | Delete task   |

##  Installation & Setup

### 1. Clone the repository

git clone https://github.com/your-username/your-repo-name.git

---

### 2. Run Backend

cd crud-app
npm install
node server.js

---

### 3. Run Frontend

cd todo-app
npm install
npm start

---

## 🌐 Output

Frontend runs on:
http://localhost:3000

Backend runs on:
http://localhost:5000

---

## ⚠️ Note

* Data is stored in server memory (not permanent)
* Data will be lost when server restarts
